# TES-139 public release record

Date: 2026-09-30

This record closes the public source release of the single-host Docker Compose
foundation as **Agent Cloud** at
[github.com/147pop/agent-cloud](https://github.com/147pop/agent-cloud). The
development repository stays private as an internal archive.

## History and asset review

Before publication, the maintainers reviewed every branch, commit, blob,
commit message and pull request of the development repository for secrets,
operational identifiers and third-party material. No private keys, tokens,
passwords or cloud credentials were found. Operational identifiers were
removed from the whole published history with `git filter-repo`:

- The dated host inventory directory (`infra/inventory/`) was removed from
  every commit; the operator keeps it privately.
- Operator IPv4 addresses were replaced with TEST-NET-3 placeholders
  (`203.0.113.x`) and private prefixes were remapped to `10.240.x`.
- Hostnames, SSH aliases, co-tenant container names, a personal domain and
  the private tracker workspace slug were replaced with neutral placeholders.
- `sources.tar.gz` snapshots were rebuilt with the sanitized contents, and the
  affected `SHA256SUMS` entries were reissued for the sanitized bytes. The
  measurements themselves were not altered; only identifiers inside the
  evidence changed.
- Author and committer e-mails were rewritten to GitHub noreply addresses.
  Names and dates are preserved: 83 commits by Agustín Emilio Pedernera and
  73 by Pablo Cardozo.

The published `main` history is therefore not commit-for-commit identical
with the development archive. Links to historical commits in the benchmark
documents point at the rewritten equivalents.

Independent re-scan before publication, over every commit of the published
history: zero occurrences of any operator IPv4 address found in the original
history, of the removed hostnames, container names, interface address,
tracker workspace slug or personal e-mail domains.

## Release changes

- New project README with the Agent Cloud identity, quickstart, architecture,
  evidence index, roadmap and origin story; brand banner in
  `docs/assets/banner.svg`.
- `SECURITY.md` now points at GitHub private vulnerability reporting.
- `CONTRIBUTING.md` describes the supported Compose runtime and no longer
  requires tracker access.
- Links to the development repository now point at this repository; links to
  the private tracker were unlinked, keeping only their `TES-…` identifiers.

Internal names (`cloud` Compose project, `cloud-control`, `cloud` CLI) are
unchanged so existing installations keep their named volumes.

The journey covered the typed EULA error, REST create and status until
`running` (46 s), a real Minecraft protocol handshake, MCP `initialize`,
`tools/list` and `minecraft_status`, CLI status, a world marker across MCP
stop and CLI start with the same endpoint, protocol refusal while stopped,
`409 capacity_unavailable` on a distinct second create, a wrong-token error
and a clean shutdown that preserved the named volumes.

The trials covered three racing creates for the single slot, idempotent
replay, conflicts on a changed body or operation, control restarts while a
start and a stop converge, and a forced container recreation that kept the
same world and endpoint. The single-writer invariants held after every trial.

Earlier platform coverage (Linux arm64, amd64 images under Rosetta) is
recorded in the [F4.3 platform reproduction](tes-157-platform-reproduction.md).
